# Smart Planner

Учебный проект: веб-приложение, которое помогает спланировать выполнение проекта.

## Идея

Пользователь добавляет задачи: сколько часов займёт каждая, какой у неё приоритет и дедлайн. Ещё можно указать, какие задачи от каких зависят (например, нельзя писать отчёт, пока не готовы расчёты).

Дальше приложение само составляет план: раскладывает задачи по дням с учётом рабочего времени и показывает результат на диаграмме Ганта.

## Что умеет (план)

- регистрация и вход, роли пользователя и администратора
- проекты и задачи с зависимостями
- автоматическое построение плана
- поиск критического пути: задачи, задержка которых сдвигает весь проект
- предупреждения, если в зависимостях есть цикл или дедлайн невозможно выполнить
- режим «что если»: как изменится план, если задача задержится

## Алгоритмы

- поиск циклов в графе зависимостей (обход в глубину)
- топологическая сортировка
- метод критического пути
- распределение задач по дням с учётом приоритетов и дедлайнов

## Технологии

- Backend: Python, FastAPI, SQLAlchemy, Alembic
- База данных: PostgreSQL
- Frontend: React, Tailwind CSS
- Тесты: Pytest
