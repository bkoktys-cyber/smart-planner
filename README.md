# Smart Planner

Учебный проект: веб-приложение, которое помогает спланировать выполнение проекта.

## Описание

Пользователь создаёт проект и добавляет в него задачи: сколько часов займёт каждая, какой у неё приоритет и дедлайн. Между задачами можно указать зависимости (например, нельзя писать отчёт, пока не готовы расчёты).

Дальше приложение само составляет план: раскладывает задачи по дням с учётом рабочего времени пользователя, находит критический путь и предупреждает, если дедлайн выполнить невозможно. Результат показывается на диаграмме Ганта.

### Возможности

- регистрация и вход по JWT, роли пользователя и администратора
- проекты и задачи с зависимостями
- автоматическое построение плана
- поиск критического пути (задачи, задержка которых сдвигает весь проект)
- предупреждения о циклических зависимостях и невыполнимых дедлайнах
- режим «что если»: как изменится план, если задача задержится

### Алгоритмы

- поиск циклов в графе зависимостей (обход в глубину)
- топологическая сортировка
- метод критического пути
- распределение задач по дням с учётом приоритетов и дедлайнов

### Технологии

- Backend: Python, FastAPI, SQLAlchemy, Alembic
- База данных: PostgreSQL
- Frontend: React, Tailwind CSS
- Тесты: Pytest

### Архитектура

Клиент-серверная. На сервере используется MVC со слоем сервисов: роутеры принимают запросы, сервисы содержат логику, модели работают с базой данных. Алгоритмы планирования вынесены в отдельный модуль.

## Установка и запуск

### Что нужно установить

- Python 3.12 или новее
- PostgreSQL 16 или новее
- Git
- Node.js 20 или новее (понадобится для frontend)

### 1. Клонировать репозиторий

```bash
git clone https://github.com/bkoktys-cyber/smart-planner.git
cd smart-planner/backend
```

### 2. Создать виртуальное окружение и установить зависимости

Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Создать базу данных

В PostgreSQL (через pgAdmin или psql) создать пустую базу `smart_planner`.

### 4. Настроить переменные окружения

В папке `backend` создать файл `.env`:

```
DATABASE_URL=postgresql+psycopg://postgres:ВАШ_ПАРОЛЬ@localhost:5432/smart_planner
SECRET_KEY=любая_длинная_случайная_строка
```

Сгенерировать `SECRET_KEY` можно командой:

```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

### 5. Создать таблицы

```bash
alembic upgrade head
```

### 6. Запустить сервер

```bash
uvicorn app.main:app --reload
```

После запуска:

- API: http://127.0.0.1:8000
- документация API (Swagger): http://127.0.0.1:8000/docs
